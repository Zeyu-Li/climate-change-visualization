# Degrees of Change frontend

A React + TypeScript app built with [Vite](https://vite.dev/). It needs Node.js 22.22 or newer and uses yarn.

## Available Scripts

In the `frontend` directory, you can run:

### `yarn start`

Runs the app in development mode at [http://localhost:5173](http://localhost:5173). The page reloads when you
make edits.

### `yarn build`

Type-checks the app and builds it for production into the `build` folder.

### `yarn preview`

Serves the production build locally, to check it before deploying.

### `yarn lint`

Lints the source with [oxlint](https://oxc.rs/docs/guide/usage/linter).
